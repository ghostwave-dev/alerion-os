## 🌟 About Alerion OS

**Alerion OS** is a fully functional web operating system designed to run smoothly right inside your browser. Built entirely from scratch using **Vanilla JS** (no heavy frameworks or libraries), it features a complete window manager, a virtual file system, customizable themes, built-in apps, and a native OTA (Over-The-Air) update checking mechanism.

Whether you want a lightweight desktop environment simulation or a showcase project for a developer portfolio, Alerion OS brings a desktop experience to the web.

---

## 🚀 Key Features

* **🪅 Window Management:** Fully interactive, draggable, resizable, minimizable, and maximizable windows.
* **⌨️ Built-in Terminal:** Custom shell (`alsh`) with standard commands (`ls`, `cd`, `cat`, `mkdir`, `touch`, `rm`, `neofetch`, etc.).
* **📁 Virtual File System:** Persistent local storage-backed file system with desktop, documents, and pictures directories.
* **⚙️ OTA Updates:** Integrated update checker system fetching remote version data (`version.json`) directly from GitHub.
* **🎨 Customization:** Multiple accent colors, wallpaper options, dark/light themes, and an initial setup wizard (OOBE).
* **📱 Responsive & Lightweight:** Optimized for speed, low resource usage, and smooth execution on any hardware.

---

## 📦 Built-in Applications

* **Terminal** (`term`) - Command-line interface.
* **Notes** (`note`) - Create, edit, and save text files locally.
* **Files** (`files`) - File manager to navigate directories.
* **Browser** (`web`) - Mini web browser with multi-tab support and search engine integration.
* **Paint** (`paint`) - Canvas-based drawing tool with PNG saving.
* **Music** (`music`) - Synthesizer and song player.
* **Calculator** (`calc`) - Functional mathematical calculator.
* **Calendar & Clock** - Date and time utilities.
* **Task Manager** (`tm`) - Monitor active windows and JS memory usage.
